Content rules

  1. Each fact once per page; link to it elsewhere.
  2. Show “No data yet” for a missing source; never hide the slot.
  3. Say “No red flags found in these sources”. Never “safe”.
  4. A checked date, who checked it, and the source level are stored. They are never shown on the live site.
  5. Mock/example data carries the yellow Mock badge.
  6. Wording changes need Alex's approval.

Logo

assets/logo/ · .logo .lockup · --logo-*

R2: white double-stroke “R” (currency style) in a violet #6C3BFF rounded square, ink “Regretamin” wordmark (outlined Bricolage 800). Dark backgrounds use the -dark files (white wordmark). To swap the logo, replace the files in assets/logo/ — every page points at the same paths.

Clear space: at least half the icon height on every side. Nav 36px, footer 28px; minimum lockup height 24px.

Dark: lockup-dark.svg / icon-dark.svg.
